小飞机网盘不限速、不登录就能下载，用着挺爽。但每次下文件都得打开分享页 → 等页面加载 → 点下载按钮，多个文件还得来回切，烦。

写了个 Cloudflare Worker，把分享链接丢进去，直接 302 跳到下载直链。不用开网页、不用点按钮、不用登录。

::btn[GitHub 仓库]{link="https://github.com/zlm6666/fjp-down" type="import"}

## 怎么用

把分享链接里的 `share.feijipan.com` 前面加上 `fjp.xiaow.qzz.io`，后面加 `?url=`：

| 参数 | 必填 | 说明 |
|---|---|---|
| `url` | ✅ | 小飞机网盘分享链接 |
| `idx` | ❌ | 文件序号，1=第一个（默认1） |
| `pwd` | ❌ | 提取码 |

```bash
# 原始分享链接
https://share.feijipan.com/s/0EdkoxGQ

# 直链下载
https://fjp.xiaow.qzz.io/?url=https://share.feijipan.com/s/0EdkoxGQ
```

### 多文件分享

如果分享里有多个文件，加 `&idx=N` 选第几个：

```bash
# 下载第二个文件
https://fjp.xiaow.qzz.io/?url=https://share.feijipan.com/s/XXX&idx=2
```

不知道有几个文件？直接访问不带 `idx`（默认第一个），如果序号超出范围，页面会列出所有文件名和对应序号：

![错误提示](https://img.tucang.cc/api/image/show/aac33b8bb1f8a44d014fc3dd96221a30)
### 带提取码

加 `&pwd=提取码`：

```bash
https://fjp.xiaow.qzz.io/?url=https://share.feijipan.com/s/XXX&pwd=1234
```

:::note{type="warning"}
不带提取码访问加密分享会提示"可能需要提取码"，带了但密码不对会提示"提取码可能不正确"。
:::

## 怎么部署

想用自己的域名？Cloudflare Worker 免费额度每天 10 万次，够用了。

### 1. 创建 Worker

打开 [Cloudflare Dashboard](https://dash.cloudflare.com/) → Workers & Pages → 创建 → 选择 **ES Module** 格式（不是 Service Worker！）。

### 2. 粘贴代码

把 [`worker.js`](https://github.com/zlm6666/fjp-down/blob/main/worker.js) 全部代码粘贴进去，点部署。

### 3. 绑定域名（可选）

触发器 → 自定义域 → 添加你自己的域名。

没有多余域名的话，直接用 CF 分配的 `xxx.workers.dev` 也行。

## 原理简述

整个流程四步：

1. 从分享链接里提取 `shareId`
2. 调小飞机 API `/ws/recommend/list` 拿文件列表
3. AES-128-ECB 加密 `fileId|userId` 生成 `downloadId`
4. 请求 `/ws/file/redirect` → 拿到 302 下载直链 → 返回给浏览器


加密部分踩了个坑：CF Workers 的 `node:crypto` 不支持 `aes-128-ecb`，最后用 `crypto.subtle` 的 `AES-CBC` + 零 IV 逐个 block 模拟 ECB 才搞定。

:::note{type="info"}
特别鸣谢[netdisk](
https://github.com/qaiu/netdisk-fast-download)
提供部分代码支持
:::
